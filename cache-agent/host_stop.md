# host_stop.sh — Stop the cache-agent from the host.

**Who runs it:** You.

**How to run it** — from the mycache folder:
```
$ cd ~/myworkspace/projectspace/mycache
$ bash cache-agent/host_stop.sh
[OK] Cache agent stopped
```

**What it does:**
1. stops the agent process inside mycache-redis; nothing to do if not running
